구성 원칙 · 확인 필요 사항

  • 파일 간 이동은 상대경로 링크, 모달은 소속 파일 안의 data-overlay로 처리합니다.
  • 중첩 모달(직종 검색 등)은 부모 모달과 같은 파일에 둡니다.
  • 각 파일이 만들어지는 대로 링크를 활성화합니다.
  • 사업장 선택 모달은 취득·사업장 이동 두 흐름이 공유하므로 가입현황에 남겼습니다.
  • 정정 신고는 드롭다운 값이 「정정」 하나뿐이라, 행의 자격 상태(취득/상실)로 대상 파일을 나눴습니다 — 취득=report-correction.html, 상실=report-correction-loss.html (가입현황에서 자동 분기).
  • 신고 내용 조회 · 상세보기는 「신고대상&진행현황」 탭 소속이며, 해당 탭은 아직 범위 밖입니다.
  • Figma 「tree」의 접수증 Layer Modal은 프리미엄 섹션에 대응 프레임이 없어 제외했습니다.
  • 전입/전출 신고는 사업장 이동 신고로 개칭된 것으로 보고 변경 그룹에 넣었습니다.
  • 근로자 추가는 Figma에 "화면 생략"으로 표기되어 제외했습니다.
